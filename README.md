# Проєкт: Планувальник навчального тижня v2.0 (Конструктор розкладів) — Варіант 11

Командний міні-проєкт, виконаний самостійно з повною імітацією Git Flow та розподілом модулів між двома ролями.
Замість консольного інтерфейсу програму реалізовано як повноцінний графічний додаток на базі **PyQt5** із підтримкою механізму Drag-and-Drop та збереженням даних.

## Функціонал додатка:

1. **Сітка розкладу (QGridLayout):** Відображення занять у вигляді фіксованої таблиці на 6 академічних слотів (від 07:45 до 18:15) для кожного дня тижня.
2. **Інтерактивний Конструктор:** Можливість швидкого наповнення розкладу шляхом перетягування (Drag-and-Drop) створених предметів із нижньої панелі-палітри у порожні слоти.
3. **Керування елементами (ПКМ):** Контекстне меню для предметів у палітрі (редагування/видалення) з каскадним оновленням їхніх назв у сітці розкладу, а також швидке очищення слоту через клік правою кнопкою миші.
4. **Менеджер пресетів (JSON):** Можливість створювати та вести окремі розклади (наприклад, на різні тижні навчання) із динамічним переключенням між ними. Глобальний пул предметів переноситься між файлами автоматично.
5. **Розумний пошук:** Підсвічування заповнених слотів у реальному часі (знайдені предмети фарбуються в зелений колір, інші заповнені — в сірий).

## Розподіл ролей (імітація Git Flow):

- **Студент A (Інтерфейс та введення):** Розробив кастомні класи віджетів (`DraggableSubject`, `ScheduleSlot`) для обробки подій миші, кліків ПКМ та Drag-and-Drop. Створив головне вікно програми та налаштував логіку керування файлами через комбобокс.
- **Студент B (Структура даних і пошук):** Реалізував бекенд додатка в класі `ScheduleManager`. Налаштував матричну структуру збереження розкладу (словник словників за днями та слотами), алгоритм каскадного перейменування, обробку пошукових запитів та серіалізацію/десеріалізацію даних у формат JSON.

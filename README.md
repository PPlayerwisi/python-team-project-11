# Проєкт: Планувальник навчального тижня (Варіант 11)

Програма по суті є календарем, в якому користувач сам розставляє собі заняття на тиждень. Програма розрахована на те, що користучав це студент

## Основний функціонал:

- Додавання занять по днях тижня.
- Перегляд повного розкладу.
- Пошук занять за назвою предмета.

## Склад команди та розподіл ролей:

- **Студент A (Team Lead / Integrator):** Даніїл — відповідає за створення структури проєкту, розробку графічного інтерфейсу (PyQt5), введення даних від користувача та фінальну інтеграцію.
- **Студент B (Developer / Tester):** Даніїл — відповідає за розробку внутрішньої структури даних, логіку збереження розкладу, алгоритм пошуку та обробку помилок.
